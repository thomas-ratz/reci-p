# Recipe website UI kit
Click-through recreation of the core website surfaces, composed from the design-system components.
- `index.html` — app shell; routes between Home, Recipe and Search (page persisted in localStorage).
- `Chrome.jsx` — Header (sticky, blurred cream) and Footer (brown, newsletter).
- `Home.jsx` — featured-recipe hero, category chips + recipe grid, "What's in your fridge?" panel.
- `RecipePage.jsx` — title block, hero image, meta bar, sticky ingredients panel with servings scaler, method steps, cook's note.
- `Search.jsx` — search field, filter sidebar, active-filter chips, results grid, empty state.
- `data.js` — sample recipes.
All imagery is striped placeholders — drop in real photography.
